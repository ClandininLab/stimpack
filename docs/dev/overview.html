§1 · Process topology

Everything is processes wired by fire‑and‑forget RPC

One message is a line of JSON — a list of {name, args, kwargs, target} requests, with no responses. A target tag routes each call to a server module; the visual module fans out to one render subprocess per screen.

§2 · Subsystems

The stimpack core, plus two lab layers

Dependencies flow one way: the labpacks import from stimpack and are loaded dynamically by file path from a YAML config. Stimpack never imports them.

stimpack.rpc

The IPC backbone

JSON‑over‑TCP transceivers, subprocess launch_server, and MyMultiCall batching. Stdlib only.

6 files · dependency‑free bottom layer
stimpack.visual_stim

The renderer

moderngl/PyQt6 perspective‑corrected engine, ~24 built‑in stimuli, shapes, trajectories, distributions, shared‑memory pixmaps.

13 files · one render process per screen
stimpack.experiment

Orchestration

BaseProtocol (parameter tiers & sweeps), client/server, the PyQt6 GUI, HDF5 data model, and the config/labpack loader.

8 files · run → epoch → pre/stim/tail
stimpack.device

Hardware I/O

DAQ triggering abstraction and the closed‑loop locomotion engine. Ships KeyTrac (keyboard) as the only concrete source.

4 files · real drivers live in labpacks
labpack

Template

The skeleton a lab clones: Client/Data/protocol/DAQ subclasses, custom stimuli, and a rig config YAML. Mostly passthrough.

14 files · copy & fill in
clandinin_labpack

Live instantiation

~15 per‑user protocol modules, rig servers, Lightcrafter/LabJack/FicTrac drivers, and per‑user configs & presets.

50 files · production fly‑VR + 2p rigs
§3 · Review — highest priority

Eight issues that can break a live experiment

Selected from 58 verified findings. Each was checked against the real code; severities are calibrated for a single‑operator lab rig on a trusted network. Full detail — plus 50 more — in IMPROVEMENTS.md.

High Medium Low · 28 Nit · 7
#1
High

RPC dispatch has no exception isolation

rpc/transceiver.py:67
A handler exception runs inside paintGL (aborts the screen process via qFatal) or inline in loop() (silently kills the server's request thread). This amplifier turns other bugs into crashes.
#2
High

Outbound RPC swallows only BrokenPipeError

rpc/transceiver.py:49
After the server dies, every call is an invisible no‑op and the sleep‑timed run marches on. ConnectionResetError isn't caught at all, so a reset kills the sending thread.
#3
High

unload_stim_module mutates the list it iterates

visual_stim/framework.py:557
On disconnect it unloads only every other module; the survivors stay in sys.modules and make the next re‑import trip a duplicate‑class assert.
#4
High

Locomotion receive_message ignores its timeout

device/…/loco_managers.py:115
A while not ready wrapper defeats the select timeout: no‑data means a busy‑spin, and close() hangs when the tracker stops streaming.
#5
High

ctx.disable(0x8DB9) is a magic constant & the wrong call

visual_stim/framework.py:213
In moderngl this doesn't disable GL_FRAMEBUFFER_SRGB (raw enums need disable_direct); the value aliases moderngl's own flags, silently toggling the wrong state under a stray debug comment.
#7
High

EGL corner square rebuilds its GL program every frame

visual_stim/square.py:107
On Wayland/EGL, the photodiode square recompiles its shader and reallocates buffers every frame without releasing the old ones — a per‑frame compile plus an unbounded GL leak, even when idle.
#8
High

SharedPixMapStimulus.close() always raises BufferError

visual_stim/shared_pixmap.py:29
A live ndarray view blocks memblock.close(), so unlink/join never run and /dev/shm leaks. With #1, this crashes the visual server at the end of the first pixmap epoch.
#16
Medium

HDF5 write errors abort the whole GUI mid‑run

experiment/data.py:173
No h5py call is guarded and the run has no try/except, so a disk‑full or dropped‑share error aborts the app via qFatal — on_run_finish never runs, leaving locomotion and triggers dangling.

Cross‑cutting theme: make the RPC layer fail loudly, not silently — per‑request exception isolation, a connection‑health flag, child‑death detection, and an optional ack channel would cover most of the "breaks a live experiment" risk at once.
